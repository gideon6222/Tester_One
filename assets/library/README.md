# assets/library/

Pre-made assets (rung 0 and rung 1) after processing, ready for this game.

The downloads themselves are shared and live once at `C:\dev\asset-library\<source>\`,
never copied into a game repo as source. What lands here is the processed GLB: recoloured
to this game's palette, decimated to the budget in `../STYLE.md`, origin at bottom centre,
scaled to metres.

A rung 1 change is a script in `C:\dev\asset-forge\recipes\`, not a hand edit, so the
next game can reuse it.

Every file here needs a line in `../LICENSES.md`.
